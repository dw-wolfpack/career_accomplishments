## Key Projects and Achievements <a id="autodesk-key-projects"></a>

- **Cost Reduction Process**: Designed and implemented a process that reduced costs by over 65% between workflows and BI layers through aggregations and storage optimization.

- **Cost Analysis Solution**: Built a solution that tracked Spark resources and run length to give the full cost of each workflow, with a dashboard to report the findings.

- **Data Engineering Curriculum**: Designed, wrote, and hosted an internal Data Engineering Curriculum, including the content, workshops, and curriculum data sets.

- **ML and AI Research**: Researched machine learning and AI approaches to optimize marketing budget through better ad placement. This was the start of a thread of revenue-facing ML that runs through Disney and Procore.

**Other work**: Salesforce and Marketo integration, the Tableau to Looker migration, certified master data sets in Spark (including the Hive to Spark migration), an automated testing framework, the metadata crawler and backend for the internal data catalog, Slack and AWS Lambda chat bots with custom ML models, a Watson AI Twitter bot for marketing, and a hackathon project using video recognition to find burn areas for replanting.
